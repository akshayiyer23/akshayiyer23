## Featured builds

### 🔒 Gated AI Lead-Research Agent
A lead-research pipeline that runs AI on a lead only after it passes a data-quality gate, and only when the agent can cite a real source. Verify email, match company, gate on both, research with a browsing agent, force a refusal when evidence is thin, write typed results to HubSpot.

On a 15-lead test set the gate skipped 47% of AI calls and produced zero fabricated fields. Every researched row came back with a dated, sourced buying signal.

Repo: `gated-ai-lead-research-agent` · Stack: Clay · Claygent (Argon) · ZeroBounce · HubSpot

### 🥁 Personal Brand GTM Engine
A two-part GTM system I built to scale cold outbound for my drumming business. $8,300 closed across 8 deals, 76% inbound. Clay finds the decision-maker at each target music company or artist, researches a real pitch angle with a gated agent that refuses to fabricate, and scores fit on two axes. n8n runs the intake-to-CRM spine: a webhook pipeline with two validation gates and an idempotent HubSpot upsert. I tested it end to end. A real lead flowed through both gates and created a contact with zero errors.

Repo: `personal-brand-gtm-engine` · Stack: Clay · Claygent · Hunter · n8n · HubSpot

### ✅ AI Brand Compliance Agent (Milliman MedInsight)
A Claude Skill that checks marketing decks against brand guidelines and returns a typed compliance report: flagged violations, severity ratings, and suggested rewrites. Built and demoed company-wide, adopted by early users on the marketing team, with rollout to 200+ employees in progress.

Repo: `brand-compliance-agent` · Stack: Claude Skill (`SKILL.md`) · Microsoft Copilot Studio

### 📊 AI GTM Analyzer
A full-stack AI web app that generates go-to-market diagnostics for any startup in seconds: ICP, GTM motion, channel performance, funnel gaps, revenue recommendations. Used in real outreach to book a meeting with a Series A CEO.

Live: project-1-eta-jade.vercel.app · Stack: Next.js · Claude API · Vercel · JavaScript
